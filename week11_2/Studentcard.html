A StudentCard is a small, independent interface that displays student information. In React, the same component can be reused with different props.

Example component

function StudentCard({ name, major }) {
  return (
    <article>
      <h2>{name}</h2>
      <p>{major}</p>
    </article>
  );
}

03 / Key takeaways

Reusable

Build a component once and use it in different places.

Props

Pass information from a parent component to a child.

Consistent

Keep the same layout while displaying different data.

A component receives props as inputs. When the parent provides different values, the same StudentCard structure can display a different student.
