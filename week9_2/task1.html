Website Performance Optimization

I improved the Web Programming Portfolio by reducing unnecessary rendering and making its assignment search more efficient, while keeping the original design and content.

← Back to portfolio

Performance improvements made

1. Reduced external requests
Removed third-party Google Fonts loading and used system fonts, reducing render-blocking and network dependencies.
2. Faster off-screen rendering
Applied content-visibility to week cards so content outside the initial viewport can be skipped until needed.
3. Lighter visual rendering
Reduced card shadows and kept hover transitions focused on simple color changes to limit paint work.
4. More efficient assignment search
Cached assignment text once and skipped repeated filtering when the normalized search query has not changed.

Lighthouse performance screenshots

The screenshots below are included as visual evidence from the Lighthouse checks supplied for this task.

How to verify

Open the portfolio in Chrome, open DevTools → Lighthouse, select Performance, and run a fresh audit. Compare the new report with the earlier screenshot, especially render-blocking requests, network dependencies, unused JavaScript, and main-thread work.

Performance scores can vary with device, browser, network, and Lighthouse settings. A new score should only be reported after running the audit.

Result

The portfolio keeps its existing layout and responsive design, with fewer external dependencies, less off-screen rendering work, lighter card painting, and a more efficient search interaction.
