# Web Programming Portfolio

This repository contains my weekly assignments and practical exercises from the Web Programming course. I use it to practise web development and keep my work organized in one place.

## Live Website

Visit the portfolio here:

**[Open the Web Programming Portfolio](https://vishal01-max.github.io/louis0/)**

You can select an assignment on the website to open its published webpage. These links open the actual webpage, not the source-code view on GitHub.

## What You Will Find

The portfolio is organized by learning week:

| Week | Main topics |
| --- | --- |
| Week 1 | HTML basics and page structure |
| Week 2 | Semantic HTML, images and content |
| Week 3 | CSS styling and the box model |
| Week 4 | CSS layouts, animations and effects |
| Week 5 | JavaScript basics and DOM interaction |
| Week 6 | Working with APIs |
| Week 7 | Book Search Application |
| Week 8 | HTML forms, validation and accessibility |

Each week has its own folder containing the related assignment files.
