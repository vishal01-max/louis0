Week 9 · Accessibility

Improving Website Accessibility

This task documents the changes made after the first accessibility check identified a contrast issue. The updated test shows an increase from 95 to 100.

Before improvement 95 / 100
→
After improvement 100 / 100

What was the problem?

The first report showed a contrast warning: the background and foreground colors did not have a sufficient contrast ratio. This can make text difficult to read, especially for people with low vision.

Changes made

I improved the page colors and checked the readability and keyboard interaction of the content. The main changes were:

  • Used darker text against a lighter background.
  • Selected link colors with stronger contrast.
  • Kept links underlined so they are not identified by color alone.
  • Added a clear focus outline for keyboard users.
  • Used comfortable line spacing and readable text sizes.

Before and after test results

These are the original screenshots from my Week 9 folder. The first image shows the contrast warning, while the second shows the updated accessibility score.

What I learned: Good accessibility is not only about getting a high score. Text should be easy to read, links should be understandable, and the page should work with a keyboard. Automated testing is helpful, but manual testing is still important.
