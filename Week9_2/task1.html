Create and publish a GitHub Pages website

A step-by-step guide to creating a repository, pushing your HTML project, and publishing it online.

Student: Bishal Bohara Date: November 3, 2026
1

Create a new repository on GitHub

Create a new repository named exactly webpro-w9.

  • Set the repository visibility to Public.
  • Do not initialize it with a README file, because the project will be pushed from your computer.
2

Prepare the project on your computer

Create a project folder and open it in your terminal or VS Code.

Initialize Git and create an index.html file containing your name and the date.

Commit your work with a meaningful message, then push it to your GitHub repository.

3

Enable GitHub Pages

In your repository, open Settings → Pages.

Under Build and deployment, select Deploy from a branch, choose main and /(root), then click Save.

Your website should become available within approximately one minute.

https://YOUR-USERNAME.github.io/webpro-w9/
4

Submit your work on the LMS

Submit both links:

  • Your GitHub repository URL: https://github.com/YOUR-USERNAME/webpro-w9
  • Your live GitHub Pages URL: https://YOUR-USERNAME.github.io/webpro-w9/
Reminder: Replace YOUR-USERNAME with your actual GitHub username. Make sure your repository is public and that index.html is in the root folder.
