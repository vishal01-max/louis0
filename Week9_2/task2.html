Deploy your Book Search App to GitHub Pages

  1. Get your Book Search App from Weeks 6–7

    Open the folder from your previous lab. Make sure it has an index.html with working search functionality.

  2. Run through the deployment checklist (Topic 8)

    Fix any absolute paths. Remove debug console.log calls. Make sure it works locally.

  3. Create a new GitHub repository

    Named webpro-book-search

    Make it Public. Do NOT initialize with README.

  4. Push your Book Search App files to the new repo

    git init, git add ., git commit -m "Deploy Book Search App", connect remote, git push.

  5. Enable GitHub Pages

    On the repo: Settings → Pages → main → root → Save.

    Wait for the site to deploy. Test the live URL.

  6. Submit the live URL

    On LMS

    Example: https://jdoe.github.io/webpro-book-search/ — test it in an incognito window first!
